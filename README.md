## HCG Store (web storefront)

The web storefront lives in [`web-hcg-store/`](web-hcg-store/). See its
[README](web-hcg-store/README.md) for setup, scripts and documentation.

```bash
cd web-hcg-store
npm ci
npm run dev
```

HCG Store (this web storefront) is separate from the planned native **HCG AppStore** application.
